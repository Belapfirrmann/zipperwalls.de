# Newsletter „Messepraxis“ (MailerLite)

- `messepraxis-vorlage.html`: Grundgerüst mit allen Modulen. Alles in [ECKIGEN KLAMMERN] ersetzen, nicht benötigte Module löschen.
- `messepraxis-01.html`: Ausgabe 01 (Frühjahrsmesse 2027) als ausgefülltes Beispiel.
- `assets/logo-farbig-440.png`: Logo für den Upload in MailerLite (Anzeige 220 px breit).

In MailerLite: Kampagne anlegen, Editor „Custom HTML“ wählen, Datei einfügen. Danach das eingebettete Logo durch das hochgeladene PNG ersetzen (Gmail zeigt eingebettete SVG nicht an) und Bildplatzhalter durch echte Fotos tauschen.
Platzhalter von MailerLite: {$name}, {$url}, {$unsubscribe}, {$preferences}.
